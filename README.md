# FitLog AI

> AI 健身追蹤 App — 跨領域作品(行動 App + AI 整合)

## 🎯 給誰用
- 健身族群記錄訓練
- 想看進度曲線的人
- 重視隱私不想註冊的人

## ✨ 功能
- 🏋️ 記錄訓練重量、次數與體重變化
- 📊 自動繪製趨勢折線圖,成效一目了然
- 🔒 免註冊免登入,資料存在本機(LocalStorage)
- 📱 手機操作最佳化的介面

## 🧰 技術棧
- HTML / CSS / JavaScript(SPA)
- LocalStorage 本機儲存
- GitHub Pages 部署
